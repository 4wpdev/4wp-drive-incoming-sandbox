# What Can the 4WP Notifications Plugin Do?

**4WP Notifications** consolidates notifications from multiple sources — WooCommerce orders, admin messages, and custom integrations — into a single in-app inbox for logged-in users. No more scattered emails or a missing place to check what happened on the site.

## Key capabilities

- **Bell icon shortcode** with an unread badge and dropdown, plus a **Gutenberg block** version
- **Full notification list shortcode** with pagination, for a dedicated notifications page
- **Admin broadcast tool** to send custom notifications to individual users or whole roles
- **WooCommerce integration** — order placement and status-change events generate notifications automatically
- **Real-time read/unread sync** across every bell, list, and block on the page
- **Type-specific icons** (cart, megaphone, link) so users can scan notifications at a glance
- **Multi-language support** out of the box (English, Ukrainian)
- **REST API and PHP hooks** for developers building custom notification sources
- **Everything stored in your own database** — nothing is sent to 4wp.dev

## Pain points it solves

1. **No central place for in-app updates.** WordPress has no built-in way to tell a logged-in user "your order shipped" or "an admin posted an announcement" without email.
2. **WooCommerce order updates get lost in inboxes.** Customers miss status changes buried in email, especially on mobile.
3. **Announcements have no delivery mechanism.** Admins need a way to broadcast a message to specific roles or users without building a mailing list.
4. **Third-party notification services raise privacy concerns.** Everything here lives in the WordPress database — no external service, no data leaving the site.
5. **Auditability matters for developers.** The plugin ships human-readable PHP with no npm build step, so the source is easy to inspect and extend.

## Who it's for

WooCommerce stores that want to surface order updates in-app, membership and community sites distributing announcements, and agencies delivering projects that need a built-in notification UX without external dependencies.
